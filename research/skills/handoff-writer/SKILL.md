# Handoff writer

The user will not reread the note. A later model will. Write for that model.

## Where

`clay10fields/database`, branch `main`, under `research/<folder>/`. Update the row in `research/README.md` in the same commit. Do not write the note in another repo.

## Required sections

1. How to use this file, including what a later session may and may not do.
2. Legend. Define n, mean, t, win, lead, not a trade, book, pass bar, and fake account in this file's meanings only.
3. Data. Path, coins, start date, end date. One table if two files were used.
4. Each test: idea in words, exact rule, result, what was changed, verdict.
5. If dollars appear: what was simulated, what was not charged, and that the ending is a rank, not a forecast. Keep the number so it is not lost.

## Do not

Do not use "dead" as a ban. Do not quote a fake-account ending as expected profit. Do not replace an earlier section with a pointer. Append, or rewrite the whole file with the old numbers kept.
